## Overview

A lightweight, vanilla HTML/CSS/JS student registration app with theme support and localStorage persistence. The codebase is modular: styles are split by feature, and scripts are split into small modules loaded in order.

## Project structure

- `index.html` — single-page app entry
- `styles/` — CSS (aggregated by `basestyle.css`)
	- `basestyle.css` — imports themes and all modules
	- `themes/` — `lightstyle.css`, `darkstyle.css`
	- `base/` — variables and global styles
	- `utilities/` — a11y, icon, text, effects helpers
	- `layout/` — page/container layout
	- `components/` — header, search, forms, custom-select, buttons, alerts, cards, table, modal, footer
	- `responsive.css` — media queries
- `scripts/`
	- `modules/` — modular JS loaded via `<script defer>` in `index.html`
		- `utils.js` — DOM helpers, polyfills, debounce, ID gen, sanitizers, avatar fallbacks, validation helpers
		- `storage.js` — localStorage load/save/upsert/delete
		- `theme.js` — init/apply/toggle theme
		- `render.js` — render cards/table and filtering
		- `controller.js` — event wiring: form, actions, custom select, search, theme toggle
	- `main.js` — legacy single-file script (not referenced)
- `storage/users.json` — sample data (not used by the current UI; persistence is localStorage)
- `icons/`, `images/`, `gif/` — assets

## Styling

- Edit variables in `styles/base/variables.css` or theme tokens in `styles/themes/*`.
- Add new component styles under `styles/components/` and import only by adding an `@import` line in `styles/basestyle.css` (keeps `index.html` unchanged).

## Scripts

- Modules expose a small API via a shared namespace: `window.App`.
- Load order in `index.html` (already set): `utils` → `storage` → `theme` → `render` → `controller`.
- Add a new module: create `scripts/modules/your-module.js` and attach exports under `window.App`. Include it before `controller.js` if `controller` depends on it.

Example pattern:

```html
<script src="scripts/modules/utils.js" defer></script>
<script src="scripts/modules/storage.js" defer></script>
<script src="scripts/modules/theme.js" defer></script>
<script src="scripts/modules/render.js" defer></script>
<script src="scripts/modules/controller.js" defer></script>
```

```js
// scripts/modules/example.js
(() => {
	const App = (window.App = window.App || {});
	App.example = { hello: () => console.log('hi') };
})();
```

## Data model

Stored in `localStorage` under the key `students`.

Student object shape:

- `id` (string) — generated by `crypto.randomUUID()` or fallback
- `firstName`, `lastName`, `email`
- `programme` (string)
- `yearOfStudy` (string)
- `interests` (string)
- `photoUrl` (string, absolute http/https)
- `registrationDate` (ISO string)

Theme preference saved under `theme` with values `dark|light`.

## How to run

- Open `index.html` directly in a browser, or use a simple static server.

PowerShell (optional):

```powershell
start .\index.html
```

## Accessibility

- Custom select is ARIA-enhanced (`listbox`, keyboard navigation, focus management) while keeping the native `<select>` for SRs and form submission.
- Search input is wired as a combobox with listbox suggestions.
- Screen-reader utility class: `.sr`.

## Extending

- New styles: add a file in `styles/components/` and import from `styles/basestyle.css`.
- New logic: add a module in `scripts/modules/` and include it in `index.html` before `controller.js` if required.
- Prefer using helpers from `App.utils` (escape, safeUrl, debounce) and `App.storage`.
